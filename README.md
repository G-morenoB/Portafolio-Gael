# Portafolio — Ubaldo Gael Moreno Bataz

React + Vite.

    npm install
    npm run dev      # desarrollo
    npm run build    # genera /dist para publicar

## Dónde editar
- **Todo el contenido** (nombre, bio, proyectos, tecnologías, contacto, foto): `src/data/content.js`
- **Colores y estilos**: `src/styles.css` (variables al inicio, en `:root`)
- **Componentes**: `src/components/` (un archivo por pieza de la página)

Para la foto, pon la imagen en `public/` y escribe su ruta en `profile.photo` (ej. `/foto.jpg`).
Para capturas de un proyecto, agrega `images: ['/p1-a.jpg', '/p1-b.jpg']` a ese proyecto.
